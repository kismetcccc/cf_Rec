# 物品对比损失改为单向目标

时间：2026-10-16。按用户要求，本次运行代码只修改 `models/LGMRecopt.py`，不修改配置、训练入口、基线或其他模型文件。模型更新记录按最新约定放在 `cf_update/`。

## 原因与范围

此前对称跨视图 InfoNCE 未得到性能改进。本次单独检验 MMHCL 启发的单向目标，并加入最终表示同视图负对；不是仅删除对称损失的一半，也不是完整复现 MMHCL。

令 z 为归一化最终物品表示，h 为归一化视觉与文本超图表示之和。S 仍为当前 TRAIN 批次正负物品 ID 去重集合。新损失为：

`mean_i[log(sum_(j!=i) exp(z_i·z_j/tau) + sum_j exp(z_i·h_j/tau)) - z_i·h_i/tau]`

- 只用最终表示 z 作锚点，不计算 h 作锚点的反向项；两侧均保留梯度，不 detach。
- 同视图自身配对被屏蔽，跨视图同 ID 正对保留在分母。
- 使用 logsumexp 与 logaddexp 保持数值稳定。少于两个不同物品时仍返回可求导的零。
- 温度 0.2、系数 1e-4、批次集合、构图、参数、前向融合、BPR 和正则项均保持不变。
- 版本标记改为 `lgmrec-opt-item-contrast-v2`，日志元数据明确标出 final anchor、同视图负对和无停止梯度。
