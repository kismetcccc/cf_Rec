## 设计

借鉴 MMHCL 的超图—融合表示对齐，采用简化的物品侧对称跨视图 InfoNCE；不是原文完整 SCL（没有用户侧、没有同视图分母项）。

超图视图 h_i = visual_global_item_i + textual_global_item_i，取 alpha 融合前的表示；最终视图 z_i = 模型最终物品表示（含行为残差）。每次 calculate_loss 仅运行一次 forward，复用中间结果，不缓存计算图。forward 默认接口仍返回用户/物品两项，推理不计算对比损失。

S = unique(batch positives ∪ batch sampled negatives)。同一物品 h_i/z_i 为正对，其他不同物品为跨视图负对。BPR 的负物品在对比任务中仍有自身的跨视图正对，两种正负含义不能混淆。去重防止同一 item ID 被当成自身负样本；不根据 VALID/TEST 标签筛选，不新增随机采样。

分别 L2 归一化 h 和 z，logits = h @ z.T / 0.2；loss_item_cl_raw = (CE(logits, diagonal) + CE(logits.T, diagonal))/2。唯一物品不足2时返回可微零值。使用稳定交叉熵，两侧都回传梯度，不 detach，不加投影网络。

总损失 = 原 BPR + 原正则 + 0.0001 * loss_item_cl_raw。

固定常量 ITEM_CL_WEIGHT=1e-4，ITEM_CL_TEMPERATURE=0.2 在模型文件顶部。它们是首轮实验设置，不是已验证最优值，不复用 cl_weight 或 alpha 的语义。batch512时最多1024个唯一物品，额外 logits 至多1024×1024。

## 实验边界

最终表示已经包含超图分量，存在共享信息导致对比任务偏容易的风险；不同 item ID 可能是语义相似物品，去重不能解决全部假负样本。双侧梯度可间接影响用户表示，但没有用户侧对比损失。不能用对比损失下降代替推荐指标改善。

与原第一版 LGMRecOpt 做同数据、同种子、同配置的 VALID 对照。保持原早停规则，TEST 最终冻结后才允许评估。此改动尚无完整三种子有效性结论。未推送 GitHub。
